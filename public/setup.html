Installatie voor GitHub Pages

STAP 1 · GEGEVENS

Alles op deze pagina gebeurt in je eigen browser. Je sleutel en wachtwoord worden nergens naartoe gestuurd.

Gratis: maak een Google Gemini-sleutel op aistudio.google.com/apikey (inloggen met je Google-account → Create API key). Die begint met AIza.
Betaald (slimmer): een Anthropic-sleutel van console.anthropic.com, begint met sk-ant-.
Minstens 12 tekens. Hoe langer, hoe veiliger, want de versleutelde sleutel staat openbaar online. Bijvoorbeeld vier losse woorden: paars-fiets-wolk-tijger.

STAP 2 · OPSLAAN IN GITHUB

  1. Klik op Kopieer hieronder.
  2. Open het bestand public/config.js op GitHub en klik op het potloodje (✎).
  3. Selecteer alles, plak de gekopieerde tekst eroverheen en klik op Commit changes.
  4. Wacht 1 à 2 minuten tot GitHub de site heeft bijgewerkt (tabblad Actions) en open Jarvis.
